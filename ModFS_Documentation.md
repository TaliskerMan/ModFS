# ModFS Documentation

The ModFS installation and user guide is [docs/ModFS_User_Guide.pdf](docs/ModFS_User_Guide.pdf). Its source text is [docs/guide/ModFS_User_Guide.md](docs/guide/ModFS_User_Guide.md), so you can also read it on GitHub. The [README](README.md) has a short overview.

ModFS is a macOS app for Apple Silicon (macOS 14 or later). It is a front end for the FSearch search engine by Christian Boxdörfer (GPLv2 or later); ModFS as a whole is distributed under the GNU GPL, version 3 or later.
